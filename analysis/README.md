# Sanitized structural analysis only

This directory may contain an approved, sanitized description of OpenAM export
structure, such as `openam-config-structure.md`, produced from corporate data by
Kilo.

Do not place real configuration files, values, hostnames, IP addresses, URLs,
DNs, usernames, secrets, tokens, certificates, or internal identifiers here.
The production parser remains blocked until the sanitized structural report is
available and reviewed.
